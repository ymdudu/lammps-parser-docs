type, public :: BaseHandler

Manage the three most basic parameters of a given configuration.

Note

The derived type BaseHandler contains 3 private integer components:

  1. ndim, the spatial dimension of the configuration.

  2. timestep, the timestep of the configuration.

  3. natoms, the number of atoms in the configuration.

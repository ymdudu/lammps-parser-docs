lammps-parser

Overview

The project "lammps-parser" is a series of Fortran modules consisting of a hierarchy of fundamental classes and routines, designed for parsing dump files generated by LAMMPS package and performing basic calculations frequently occurred in molecular dynamics simulation.

To accelerate the computation, "lammps-parser" also supports parallelism based on OpenMP for a few procedures with large computational scale.

The project "lammps-parser" is mainly written in Fortran (2008) language and uses OOP techniques, enabling itself to have a great extensibility, although it is developed for the author's own research at the beginning.

Usage

Dependencies:

  • GNU Fortran

  • Intel oneAPI toolkits (particularly Intel Fortran Compiler and Intel MKL)

  • voro++ package

The codes will be built as a (static or dynamic) library in folder "lib/".

# Make sure that all dependencies have been installed and can be accessed by ${PATH}.
# Suppose that the current working directory is the root directory of lammps-parser:
cd src
make [FC=ifx|gfortran]

After building the library "liblammps-parser.a" (or "liblammps-parser.so"), everyone will be able to write his/her source codes using the facilities provided by "lammps-parser" via linking to the library just created.

A module for fundamental statistical analysis.

Note

  1. 1d probability distributions, including pmf, pdf for int, single, double data.
  2. Pearson correlation, Spearman rank correlation.
  3. Sort algorithm, including ascending and descending sort.

interface

  • public module function get_rank(arr, rank_mode) result(rank)

    get the rank for each element in an array, according to an integer "rank_mode".

    Note

    Different rank mode can be specified:

    1. rank_mode = 0 (default), fractional ranking ("1 2.5 2.5 4" ranking)

    2. rank_mode = 1, std competition ranking ("1224" ranking)

    3. rank_mode = 2, mod competition ranking ("1334" ranking)

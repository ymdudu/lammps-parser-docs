type, public :: BoxHandler

Manage all box parameters.

Note

  1. The box is valid if and only if bounds is ALLOCATED and bounds(idim, 1) < bounds(idim, 2) for .

  2. THE ONLY WAY TO CHANGE THE STATUS OF VALIDNESS is reallocBounds(), and setValid().

  3. In particular, the status of "isValid" is set to false right after reallocBounds(), forcing one to check whether or not the box is valid after reading from file.

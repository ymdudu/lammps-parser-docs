type, public :: PositionHandler

Manage the atomic positions information in a configuration.

Note

The positions is valid if and only if "positions" is ALLOCATED and all atom positions lie in the range of box bounds, i.e.

  1. scale mode: positions(iatom, idim) for .

  2. noscaled mode: similar with scale mode.

THE ONLY WAY TO CHANGE THE STATUS OF VALIDNESS is reallocPositions(), and setValid().

In particular, the status of "isValid" is set to false right after reallocPositions(), forcing one to check whether or not the positions is valid after reading from file.
